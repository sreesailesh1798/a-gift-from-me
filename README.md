## 🚀 How to Run & View Locally

### Option 1: Direct Double Click
Simply double-click [`index.html`](file:///C:/Users/harik/.gemini/antigravity/scratch/romantic-proposal-website/index.html) to open it directly in Opera, Chrome, or Edge!

### Option 2: Python Local Server
Run this command in terminal inside this directory:
```powershell

```
Then open [http://localhost:8080](http://localhost:8080) in your browser.
